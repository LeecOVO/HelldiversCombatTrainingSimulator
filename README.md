### 🌌 游戏背景
在《绝地潜兵 2》（HELLDIVERS™ 2）中，玩家作为超级地球的精英战士，肩负着传播“管理民主”的重任。在激烈的战场上，玩家必须通过键盘（或手柄）输入特定的方向键序列来呼叫“战备”（Stratagems）——包括空袭、重型武器支援和补给。在高压战斗中，快速且准确地输入指令是每一位绝地潜兵的生存必备技能。

---

### 🎯 项目背景与目的
**Helldivers Combat Training Simulator** 是一个非官方的粉丝制作工具，旨在通过模拟游戏内的呼叫终端，帮助玩家肌肉记忆战备指令。
*   **核心目标**：提升玩家在实战中输入战备指令的速度和准确度。
*   **评分系统**：根据输入响应时间（毫秒）提供五星级评分反馈，激发训练热情。

---

### 🛠️ 功能特性
-   **真实还原**：使用键盘 `W`, `S`, `A`, `D` 对应游戏内的上下左右箭头。
-   **战备数据**：包含多种核心战备（如通用机枪、长矛导弹等），配备官方图标和中英文对照。
-   **视觉风格**：模拟《绝地潜兵 2》标志性的黄色高亮 UI 和霓虹发光效果。
-   **实时反馈**：输入正确即刻高亮，输入错误自动重置并闪烁提醒。
-   **多语言支持**：支持简体中文（zh）和英文（en）。
